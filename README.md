## 📋 Περιγραφή

Το **ΟΙΝΟΠΟΡΟΣ** είναι μια διαδραστική εκπαιδευτική εφαρμογή (web app) που εξερευνά τον οινοτουρισμό στο νησί του Πόρου και την ευρύτερη περιοχή Τροιζηνίας. Αναπτύχθηκε ως εργασία στο μάθημα **«Τεχνολογίες Έξυπνου Τουρισμού»** του Τμήματος Πληροφορικής, Πανεπιστήμιο Πειραιώς (ακαδ. έτος 2025–2026).

Η εφαρμογή καλύπτει τρεις θεματικές ενότητες:

- **Ιστορία & Παράδοση** — Η ρετσίνα του Πόρου, η αμπελουργική κληρονομιά, η σύνδεση με την Τροιζηνία
- **Ποικιλίες & Terroir** — Ελληνικές αυτόχθονες ποικιλίες σταφυλιών, κλίμα, γεωλογία, ο κύκλος του αμπελιού
- **Οινοτουρισμός & Γευσιγνωσία** — Wine routes, τα 5 βήματα γευσιγνωσίας, food & wine pairing

---

## ✨ Χαρακτηριστικά

### Εκπαιδευτικό Περιεχόμενο
- 3 ενότητες × 3 sections = **9 μαθησιακές ενότητες** με κείμενο, εικόνες και βίντεο
- Πληροφορίες για τα **κρασιά του Porou Ampelos** (8 τοπικές ετικέτες) και του **Οινοποιείου Ανδρέου**
- Ενσωματωμένα YouTube βίντεο για ρετσίνα, ελληνικές ποικιλίες, οινοτουρισμό

### Αξιολόγηση & Δραστηριότητες
- **Quiz ανά ενότητα** (5 ερωτήσεις πολλαπλής επιλογής με επεξηγήσεις)
- **Τελικό Quiz** (8 ερωτήσεις από όλες τις ενότητες — ξεκλειδώνεται μετά την ολοκλήρωση)
- **Διαδραστικές δραστηριότητες**: Matching (αντιστοίχιση) και Ordering (σωστή σειρά)

### Προσαρμοστική Μάθηση
- Καταγραφή **προτιμήσεων χρήστη** κατά την εγγραφή
- **Αυτόματες προτάσεις** βάσει προόδου (νέο / σε εξέλιξη / χρειάζεται επανάληψη / κατακτημένο)
- Παρακολούθηση **επισκέψεων ανά section**

### Διαδραστικός Χάρτης
- **Leaflet/OpenStreetMap** χάρτης με 9 σημεία ενδιαφέροντος (wine route Πόρου–Τροιζηνίας)
- Emoji markers ανά κατηγορία (🍷 οινοποιείο, 🌿 φύση, ⛵ μεταφορά, 🏛️ πολιτισμός)
- Sidebar με λίστα στάσεων και flyTo animation
- Polyline διαδρομής

### Dashboard & Στατιστικά
- **Radar Chart** — Ικανότητες ανά ενότητα (quiz, υλικό, δραστηριότητες)
- **Bar Chart** — Βαθμολογίες Quiz (καλύτερο / τελευταίο)
- **Line Chart** — Εξέλιξη βαθμολογίας στον χρόνο
- **Horizontal Bar** — Συχνότητα επισκέψεων ανά ενότητα
- **Πιο δύσκολες ερωτήσεις** — ποσοστό λάθους ανά ερώτηση
- Ιστορικό τελικού quiz

### Αποθήκευση Δεδομένων
- **localStorage** — αυτόματη αποθήκευση προόδου χρήστη
- Δυνατότητα επαναφοράς (reset)
- Καταγραφή: username, βαθμολογίες, επισκέψεις, χρόνος μελέτης, στατιστικά ερωτήσεων

## 🚀 Εγκατάσταση & Εκτέλεση

### Προαπαιτούμενα
- [Node.js](https://nodejs.org/) (v18+)
- npm (έρχεται με το Node.js)

### Βήματα

```bash
# 1. Clone το repository
git clone https://github.com/<username>/oinoporos.git
cd oinoporos

# 2. Εγκατάσταση dependencies
npm install

# 3. Εκκίνηση development server
npm run dev
```

Η εφαρμογή θα τρέχει στο `http://localhost:5173`

### Build για production

```bash
npm run build
npm run preview
```
